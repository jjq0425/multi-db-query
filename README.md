# 多数据库查询机器人 - Web版

一个功能强大的多数据库查询机器人，支持并行查询多个MySQL数据库，并提供现代化的Web界面进行配置和管理。

> 本项目主要为 code agent（copilot） 项目搭建，用于辅助开发和测试多数据库查询功能。仅供测试使用，请勿用于生产环境。

## 功能特性

### 核心功能

- **并行查询**：同时查询多个MySQL数据库
- **实时状态**：WebSocket实时显示查询进度
- **Web界面**：现代化的响应式设计
- **飞书通知**：查询完成自动发送通知到飞书
- **查询历史**：完整的查询记录和结果保存

### 高级特性

- **自定义配置**：支持添加、编辑、删除数据库配置
- **SQL编辑器**：语法高亮和格式化功能
- **连接测试**：实时测试数据库连接状态
- **进度显示**：详细的查询进度和统计信息
- **结果可视化**：表格形式展示查询结果
- **快捷键支持**：Ctrl+S执行查询，Ctrl+Enter保存配置

## 技术栈

- **前端**：HTML5 + CSS3 + JavaScript + Tailwind CSS v3 + Font Awesome
- **后端**：Node.js + Express + WebSocket

## 使用指南

### 执行查询

1. **选择数据库**：在"执行查询"标签页中勾选要查询的数据库
2. **输入SQL**：在SQL编辑器中输入查询语句
3. **执行查询**：点击"执行查询"按钮或使用快捷键Ctrl+S
4. **查看结果**：查询结果将在下方实时显示

### 配置管理

1. **添加数据库**：在"配置管理"标签页点击"添加数据库"
2. **编辑配置**：点击数据库卡片上的编辑按钮
3. **测试连接**：在数据库配置模态框中点击"测试连接"
4. **保存配置**：点击"保存配置"按钮或使用快捷键Ctrl+Enter

### 飞书集成

1. **获取Webhook**：飞书群聊 → 设置 → 智能群助手 → 添加机器人 → 自定义机器人
2. **配置Webhook**：在"配置管理"标签页中粘贴飞书Webhook地址
3. **启用通知**：勾选"启用飞书通知"选项
4. **接收通知**：查询完成后将自动发送通知到飞书群

## 配置说明

### 数据库配置参数

| 参数                 | 说明                 | 示例         |
| -------------------- | -------------------- | ------------ |
| **名称**       | 数据库显示名称       | 生产数据库1  |
| **主机地址**   | 数据库服务器IP或域名 | 192.168.0.0 |
| **端口**       | 数据库端口号         | 3306         |
| **数据库名称** | 要连接的数据库名     | casibase     |
| **用户名**     | 数据库登录用户名     | root         |
| **密码**       | 数据库登录密码       | 0000       |
| **启用状态**   | 是否启用该数据库     | 是/否        |

### 默认配置

请参考 `config_template.json`



## 安全考虑

1. **密码存储**：数据库密码以明文形式存储在config.json中，请确保文件权限为600
2. **网络安全**：建议在生产环境中使用HTTPS
3. **访问控制**：可考虑添加用户认证中间件
4. **SQL注入**：应用不对SQL语句进行过滤，请确保只执行可信的查询

## 部署建议

### 开发环境

- 直接使用 `npm start`启动
- 可使用 `npm run dev`启用热重载

### 生产环境

1. **使用PM2进程管理**：

```bash
npm install -g pm2
pm2 start server.js --name "database-query-bot"
pm2 startup
pm2 save
```

2. **配置Nginx反向代理**：

```nginx
server {
    listen 80;
    server_name your-domain.com;
  
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

3. **启用HTTPS**：使用Let's Encrypt获取免费SSL证书

## 常见问题

### Q1: 连接数据库失败怎么办？

A1: 检查以下几点：

- 数据库服务器是否在线
- 网络连接是否正常
- 端口是否开放
- 用户名密码是否正确
- 数据库是否存在

### Q2: 飞书通知发送失败？

A2: 检查：

- Webhook地址是否正确
- 网络是否能访问飞书API
- 飞书机器人是否被禁用

### Q3: 查询执行时间过长？

A3: 可以：

- 调整queryTimeout配置
- 优化SQL查询语句
- 增加服务器资源

### Q4: 如何备份配置？

A4: 定期备份config.json文件和queryHistory localStorage数据
